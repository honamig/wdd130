Client / Developer Project Report

Client Report

How did you decide what content and images to use for your site plan?

The website plan I created is for a site that introduces Japan’s hidden gems and local specialties. Since the content featured on this site is fictional rather than real, the images were generated by AI, and I wrote the text based on those images. I created this website plan because, as someone from Japan, I thought it would be interesting to build a website featuring information that only locals would know.

How did you communicate with your developer? Was there any issues with communication?

I communicated with the developer in person quite often. She built the site based on my site plan and asked me for feedback in person, so we discussed how to make the design better match my vision. I didn’t encounter any particular issues with our communication.

Did your developer meet your expectations for your site?

My developer did a great job meeting my expectations for the site. She styled it exactly according to the site plan I provided, and I especially love the hero section.

What will you do differently next time you hire a developer to do a project for you?

I realized that the site plan I created this time alone wasn’t enough to fully convey my ideas to the developer. So, next time, I plan to either explain my vision more thoroughly in person beforehand to ensure we’re on the same page, or write a more detailed and thorough site plan.

Lead Developer Report

How did you communicate with your client? Was there any issues?

I mainly communicated with the client via email. The images included in the initial site plan he sent me were blurry, so I asked him to resend them in a different format, but this didn’t cause any particular problems as we moved forward with building the site.

How did you handle publishing your client's site and sharing it with the client?

After sending him a link to the GitHub page via email so he could check the layout, I sent him a ZIP file containing the code.

How was your experience with managing your site with GitHub?

This wasn’t my first time using GitHub. I had previously created a repository on GitHub and worked on a project with others, so I had no trouble managing my site on GitHub.

General Experience and Reflections

What was the most challenging part of this project for you? Were you able to overcome it?

The most challenging part was styling the design to match the site plan. It took numerous adjustments to make it look exactly like the wireframe the client had created, but in the end, I was able to create it exactly as I had envisioned.

What did you enjoy most about this project?

Building a website was a lot of fun for me, so I enjoyed the entire process from start to finish. It made me really happy to see the site gradually take on the look I envisioned through the code I wrote.

What would you do differently if you could do the project again?

I think I would have achieved better results if I had managed the project a little more systematically and sought feedback from or reported to the client more frequently.

Do you feel more confident in working on real-world projects after this experience? Explain.

Yes, because I’ve gained another new experience, and that helps me feel more confident.
